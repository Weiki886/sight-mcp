# Sight MCP v0.2.1 发布说明

**语言 / Language：** 中文 · [English](v0.2.1.en.md)

> 状态：准备发布

Sight MCP
v0.2.1 是维护性补丁版本：无新功能、无破坏性变更，工具契约、错误码与配置项全部兼容。本版本同时是 npm
Trusted Publisher（OIDC）发布链合入后的首次真实发布，npm 包自此携带 provenance。

## 变更

### 依赖

- 生产依赖：zod 4.4.3 → 4.6.2（补丁级升级，含 zod
  4.5 引入的递归 schema 内存泄漏修复；项目未使用任何变更行为的 API）；
- 开发依赖：eslint 10.10.0、typescript-eslint 8.70.0、vitest 5.0.0（已逐条核对 vitest
  5 破坏性清单，项目用法均不命中）。

### CI 与供应链

- actions/checkout 7.0.1、actions/setup-node 7.0.0、pnpm/action-setup 6.1.0，均保持完整 SHA 固定；
- 接入 Dependabot：minor/patch 分组、大版本独立 PR，typescript 大版本在 typescript-eslint 支持 TS
  7 前临时忽略（typescript-eslint/typescript-eslint#10940）。

### 仓库治理与元数据

- 新增 SECURITY.md / CONTRIBUTING.md（中英成对）与 Issue/PR 模板，并开启 GitHub 私密漏洞报告；
- `docs:check` 门禁扩展覆盖根级治理文档；
- 补充 npm keywords 与 GitHub topics；
- 发布流程补充规则：GitHub Release 正文中的链接必须使用指向标签的绝对 URL。

## 安装与校验

```sh
npx -y @weiki/sight-mcp@0.2.1
npm view @weiki/sight-mcp@0.2.1 dist.integrity dist.tarball
```

## 升级说明

从 v0.2.0 升级无破坏性变更，无需修改配置。升级后建议重启宿主中的 MCP 服务以加载新代码。
