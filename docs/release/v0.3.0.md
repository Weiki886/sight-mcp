# Sight MCP v0.3.0 发布说明

**语言 / Language：** 中文 · [English](v0.3.0.en.md)

> 状态：准备发布

Sight MCP v0.3.0 移除了全部内置 Provider
profiles，改为完全由用户配置的通用 OpenAI 兼容端点接入。上游 `deepseek-v4-flash-vision-exp`
已下线，硬编码模型的维护模式难以为继；自本版本起，端点与模型只来自环境变量，模型升级、下线、更换都由使用者自己掌控，不再需要等待发版。决策记录见
[ADR 0004](../adr/0004-generic-provider-configuration.md)。

## 破坏性变更

- 移除 `--provider qwen|deepseek` 参数；传入时以状态码 `2` 退出并输出迁移指引。
- 移除 `SIGHT_QWEN_API_KEY` / `SIGHT_DEEPSEEK_API_KEY` 环境变量（不再读取）。
- `SIGHT_PROVIDER_BASE_URL` 与 `SIGHT_PROVIDER_MODEL`
  现在总是必填（原 profile 用户此前由内置组合隐式提供）。
- `credentials status` 必须显式给出账户名（Keychain 无法枚举条目）。

## 迁移指南（0.2.x → 0.3.0）

1. 在宿主环境变量中显式设置端点与模型。原 qwen profile 等价于：

   ```text
   SIGHT_PROVIDER_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
   SIGHT_PROVIDER_MODEL=qwen3.8-flash
   ```

2. 从宿主服务参数中移除 `--provider`。
3. 环境密钥改用 `SIGHT_PROVIDER_API_KEY`；macOS Keychain 用户设置 `SIGHT_PROVIDER_KEYCHAIN_ACCOUNT`
   指向账户名——既有 `qwen` 条目可直接复用（`SIGHT_PROVIDER_KEYCHAIN_ACCOUNT=qwen`），无需重新录入。
4. 未使用 profile 的通用模式用户无需任何改动。

## 变更

### Provider 配置（[Issue #63](https://github.com/Weiki886/sight-mcp/issues/63)）

- 端点与模型完全由 `SIGHT_PROVIDER_BASE_URL` + `SIGHT_PROVIDER_MODEL`
  决定，可接入任意 OpenAI 兼容视觉端点（本地或远程）；
- API 密钥解析顺序固定为：`SIGHT_PROVIDER_API_KEY` →
  `SIGHT_PROVIDER_KEYCHAIN_ACCOUNT`（新增）指定的 macOS
  Keychain 条目；两者都未设置时按无鉴权端点处理；显式指定账户但缺失/查询失败时启动失败即关闭；
- 凭据命令泛化为任意账户名：`credentials set|status|delete <account> [--yes]`，账户名经字符集校验（1–64 字符）；Keychain
  service 名不变，既有条目保留；
- Host 冒烟脚本 `--profile qwen|deepseek` 改为 `--live`（端点/模型/密钥全部由运行器环境变量注入）；
- README、配置规范、威胁模型、测试策略、Provider 指南与发布 runbook 全部双语同步，ADR
  0002 的 profiles 设计标注为被 ADR 0004 取代。
