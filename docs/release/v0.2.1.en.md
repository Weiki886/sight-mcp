# Sight MCP v0.2.1 Release Notes

**语言 / Language：** [中文](v0.2.1.md) · English

> Status: ready to publish

Sight MCP v0.2.1 is a maintenance patch: no new features and no breaking changes; the tool contract,
error codes, and configuration remain fully compatible. It is also the first release published
through the npm Trusted Publisher (OIDC) pipeline, so the npm package carries provenance from this
version onward.

## Changes

### Dependencies

- Production: zod 4.4.3 → 4.6.2 (patch-level upgrade, includes the fix for the recursive schema
  memory regression introduced in zod 4.5; the project uses none of the APIs whose behavior
  changed);
- Development: eslint 10.10.0, typescript-eslint 8.70.0, vitest 5.0.0 (the vitest 5 breaking-change
  list was reviewed item by item; none affect this project).

### CI and Supply Chain

- actions/checkout 7.0.1, actions/setup-node 7.0.0, pnpm/action-setup 6.1.0, all still pinned by
  full SHA;
- Dependabot enabled: grouped minor/patch updates with majors as individual PRs; typescript majors
  temporarily ignored until typescript-eslint supports TS 7
  (typescript-eslint/typescript-eslint#10940).

### Repository Governance and Metadata

- Added SECURITY.md / CONTRIBUTING.md (Chinese-English pairs) plus Issue/PR templates, and enabled
  GitHub private vulnerability reporting;
- The `docs:check` gate now covers root-level governance documents;
- Added npm keywords and GitHub topics;
- Release process rule added: links inside GitHub Release notes must use absolute tag-pinned URLs.

## Installation and Verification

```sh
npx -y @weiki/sight-mcp@0.2.1
npm view @weiki/sight-mcp@0.2.1 dist.integrity dist.tarball
```

## Upgrade Notes

Upgrading from v0.2.0 is non-breaking and requires no configuration changes. Restart the MCP server
in your host after upgrading to load the new code.
